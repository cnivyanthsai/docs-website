We offer a cloud integration for reporting your Azure Container Apps data to our platform. Here we explain how to activate the integration and what data it collects.

## Activate the integration [#activate]

To enable the integration follow standard procedures to [activate your Azure service in New Relic](/docs/infrastructure/microsoft-azure-integrations/getting-started/activate-azure-integrations).

## Configuration and polling [#polling]

You can change the polling frequency and filter data using [configuration options](/docs/integrations/new-relic-integrations/getting-started/configure-polling-frequency-data-collection-cloud-integrations).

Default [polling](/docs/infrastructure/microsoft-azure-integrations/getting-started/azure-integration-polling) information for the Azure Container Apps integration:

* New Relic polling interval: 5 minutes

## Find and use data [#find-data]

To find your integration data, go to <DNT>**[one.newrelic.com > All capabilities](https://one.newrelic.com/all-capabilities) > Infrastructure > Azure**</DNT> and select the integration.
